# 🇨🇳 中文

## ⚠️ 签名已更换（安装前必读）

正式版改用**全新的签名密钥**。Android 把签名当作应用身份的一部分，所以：

- **无法覆盖安装**：必须先**卸载旧版**（含 1.0.4a / 1.0.4b 测试版），才能装这个正式版。
- **卸载会清掉**：草稿箱、全部设置（路径 / 主题 / 语言 / 线程数…）。若你没授予「所有文件访问」权限，旧版私有目录里的备份与回收站也会一起丢失。
- **公共目录不受影响**：`Download/Nibnya/` 里的工作副本、备份、回收站、导出文件都还在，装好新版后照常可用。
- 以后所有版本（含测试版）都用这把新签名，**不会再要求卸载**。

建议顺序：**先把需要的存档导出或备份 → 卸载旧版 → 安装正式版 → 设置里「📦 迁移旧数据」**。

## 新增

1. **ROOT 支持**：统一提权层，ROOT / Shizuku / 正常三种模式。root 检测不是看 `su` 文件在不在，而是真跑一次 `su -c id` 查 `uid=0` —— 装了 su 但没授权、假 root 都不会误判。
2. **运行模式选择器**：设置里点一下就地展开（不是弹窗）：自动 / ROOT / Shizuku / 正常。选 ROOT 但没 root 会自动降级到 Shizuku，再不行降正常模式，并 toast 告知实际生效的模式。
3. **自定义 su 命令模板**：可改写 `su -c {cmd}` 的形式（适配 Magisk / KernelSU / 改版 su）。另附三个预设（`su -c`、`su -0 -c`、`su --mount-master -c`），点选后立即实测并告诉你这个模板通不通。模板必须含 `{cmd}` 才允许保存。
4. **「软件内部」路径**：路径选择新增 `/data/user/0/<包名>/games/com.mojang/minecraftWorlds/` —— 这是 Minecraft 真正的应用私有目录。**仅在真实 root 下显示**，每次打开都重新实测。
5. **写回改用原子替换**：新数据先完整落到同分区的临时目录，原目录改名让位，新目录顶上，成功才删旧、失败立刻回滚。任何时刻原存档都完整存在。另加写回自检（`CURRENT` 必须存在、不能有嵌套），异常自动回滚。
6. **存档缩略图真正显示**：标准路径在 `Android/data` 下，Android 11+ 分区存储让直接读文件必然失败，以前三个方块永远是灰底。改为经提权通道把字节流读进内存解码，全程不落盘。
7. **存档列表三行布局**：世界名 / 文件夹 ID / 最后游玩时间拆成三行，名字再长也挤不掉时间。
8. **边缘滑动侧边栏**：左边缘 18dp 内右滑拉出，已打开时任意位置左滑收起。
9. **夜间模式真正适配**：两套色板，76 处硬编码颜色改为主题色；系统弹窗（设置 / 备份 / 恢复 / 根节点操作等）一并跟随。
10. **权限检查并入设置**：主页顶部精简为「清理缓存 / 切换路径」，权限检查移进设置并改为真实探测。
11. **种子单击复制**：不再需要长按选中，也不会把 emoji 一起复制。
12. **自由裁剪按行列出图**：选 5×5 现在会正确切成 25 张，不再只出 1 张。
13. **锁定正方形自动调整**：打开「锁定比例（正方形）」时裁剪框立刻收敛成最大正方形，不用手动拖。

## 修复

1. **写回后游戏读不了存档（最严重）**：root 写出的文件归属是 `root:root`，而 Minecraft 以自己 uid 运行、权限位只有 `rw-------` —— 文件明明在、大小也正常，游戏却报「未找到本地服务器」，列表还显示 `4167549952` 这种荒谬体积。现在写回前会把归属还给该存档所属的应用。
2. **归属修复的自我循环**：旧逻辑优先读「当前 db 目录」的归属，一旦被写坏成 root 就一直读回 root，每次保存继续写坏。改为以应用自己的目录归属为准。
3. **su 命令被外层 shell 拆断**：命令含 `&&` 时只有第一段进了 root，后面的段落跑在普通应用身份上，`cp` 直接 `Permission denied`，看起来像「root 写不了」。改为把整条命令作为单个参数交给 su。
4. **root 下无法删除「软件内部」存档**：`/data/...` 只有 root 能看见，原生存在性判断恒为 false，明明存档在却提示「找不到存档目录」。
5. **老坏档自动修复**：打开存档时自动检查归属，之前被写坏的存档不用重新保存也能救回。
6. **Android 16 / HyperOS 保存失败只说「无法写入」**：现在真实探测能否写入，并给出可操作的解决路径（HyperOS 需单独开启「USB 调试（安全设置）」）。
7. **侧边栏三个交互问题**：关闭后再次滑动失效、遮罩层点不到（会穿透到主界面）、无法从右往左关闭。
8. **首次滑动只出现遮罩 / 宽度算错**：控件刚显示时宽度读成 0。
9. **命令安全加固**：`rm -rf` 只允许作用于临时目录与回收站；拒绝「上一级」目录、通配符、裸变量。`mv` 的源与目标也走同一套校验。

# 🇬🇧 English

## ⚠️ Signing key changed (read before installing)

This stable build uses a **brand-new signing key**. Android treats the signature as part of the app's identity, therefore:

- **You cannot install over the old version.** Uninstall the previous build (including the 1.0.4a / 1.0.4b test builds) first.
- **Uninstalling clears**: the draft box and all settings (path / theme / language / thread count…). If "All files access" was never granted, backups and the recycle bin inside the old app-private directory are lost too.
- **Public folders are unaffected**: working copies, backups, the recycle bin and exports under `Download/Nibnya/` all survive and keep working.
- From now on every build (test builds included) uses this key, so you will **not** need to uninstall again.

Suggested order: **export or back up anything you need → uninstall the old build → install this one → use "📦 Migrate old data" in Settings**.

## Added

1. **ROOT support**: a unified privilege layer with ROOT / Shizuku / Normal modes. Detection actually runs `su -c id` and checks for `uid=0`, so "su installed but not granted" and fake root are never misdetected.
2. **Execution mode selector**: expands in place in Settings (no pop-up). Choosing ROOT without root falls back to Shizuku, then Normal, with a toast reporting what actually took effect.
3. **Custom su template**: change the `su -c {cmd}` form (Magisk / KernelSU / modified su). Three presets included — tapping one runs a real test and reports whether it works. A template must contain `{cmd}` to be saved.
4. **"App internal" path**: `/data/user/0/<package>/games/com.mojang/minecraftWorlds/`, shown only when real root is available and re-tested every time.
5. **Atomic write-back**: data is staged in a temp directory on the same partition, the original is renamed aside, the new one takes its place; the old copy is removed only on success and failures roll back immediately. A structural self-check rolls back on anomalies.
6. **World thumbnails actually appear**: bytes are streamed through the privilege channel and decoded in memory instead of relying on direct file reads.
7. **Three-line world list**: name / folder ID / last played on separate rows.
8. **Edge-swipe sidebar**: swipe right within 18dp of the left edge to open, swipe left anywhere to close.
9. **Dark mode properly supported**: two palettes, all 76 hard-coded colours replaced with theme colours; system dialogs follow along.
10. **Permission check moved into Settings** and changed to a real probe.
11. **Seed copies on a single tap**, without the emoji.
12. **Free crop honours the row/column count**: 5×5 now produces 25 maps instead of 1.
13. **Square lock adjusts automatically** when enabled.

## Fixed

1. **Saves written under root were unreadable by the game (most serious)**: files owned by `root:root` while Minecraft runs as its own uid with `rw-------`, so files existed and looked fine yet the game reported "Unable to connect to world" and showed an absurd `4167549952`. Ownership is now handed back to the owning app.
2. **Ownership repair looped on itself**: the db directory's own ownership was trusted, so once corrupted to root it stayed root forever. The app's own directory is now authoritative.
3. **The su command was split by the outer shell**: with `&&`, only the first part ran as root and `cp` failed with `Permission denied`. The whole command is now a single argument.
4. **Deleting an "app internal" world failed under root**: `/data/...` is only visible to root, so the native check always said "not found".
5. **Automatic repair for already-broken saves** when a world is opened.
6. **Android 16 / HyperOS only said "cannot write"**: now probes real writability with an actionable fix.
7. **Three sidebar interaction bugs**: swipe failing after close, unclickable scrim, no right-to-left close.
8. **First swipe only showed the scrim / wrong width**.
9. **Command safety hardening**: `rm -rf` limited to temp directories and the recycle bin; parent directories, wildcards and bare variables refused; `mv` validated too.
