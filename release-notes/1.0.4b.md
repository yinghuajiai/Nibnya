# 🇨🇳 中文

## 🐛 修复

1. **切换语言后「点了没反应」**
   备份列表用的是 `StateFlow`，而它在**新值与旧值相等时不会通知**；扫同一个存档两次的结果本来就相等，
   于是点「恢复备份」**毫无反应**（连提示都没有）。
   已改为**事件通道**，点一次必然弹一次。
   另外：已选存档时直接列出该存档的备份，不再把用户丢回存档选择器。

2. **切英文后 NBT 值仍是中文**（真根因）
   取字符串用的是 **Application 的 Context**，而它**不跟随应用内的语言设置**，永远按**系统语言**输出。
   所以「系统中文 + 应用英文」时，按钮是英文、值却是「0: 生存 / 1: 创造」。
   已改为按**应用自己的语言**构造 Context（资源文件也按它取）。

3. **切换语言会留下旧语言残影**
   `recreate()` **不会销毁 ViewModel**，翻译缓存与已渲染的列表/树文本都不会更新。
   已改为**彻底重启应用**。
   按你的要求：点切换时**先弹说明框**（会重启、未保存的编辑会先进草稿箱），确认后才切；
   并在切换前先把当前编辑落盘到草稿箱。

4. **权限说明弹窗「刚出现就被系统设置页顶掉」**
   启动时有**两条**申请路径，其中一条**没有任何弹窗就直接跳系统设置**，把说明弹窗顶掉了。
   已删除启动时的无条件申请，改为**唯一入口**且**一律先说明**，用户点「前往授予」才跳转。
   申请时机推迟到真正需要时（保存 / 切换路径 / 手动点「检查权限」），并支持勾选「不再提示」。

5. **启动时的旧数据迁移提醒不出现**
   它被权限弹窗挡在后面；而且原设计「只提醒一次」——被挡掉或被随手点「暂不」就**永久不再提醒**。
   已改为**只要旧目录里还有东西就提醒**（迁完或你自己清空后，自然就不再弹）。

## 📌 本次不涉及

- 图标、应用名、包名、数据目录迁移逻辑（与 1.0.4a 一致，未改动）
- 大存档内存、地图平面编辑等已知问题（仍在待办）

# 🇬🇧 English

## 🐛 Fixed

1. **"Nothing happens" after switching the language**
   The backup list used a `StateFlow`, which **does not emit when the new value equals the old one** —
   and scanning the same world twice returns equal results. So tapping "Restore backup" did **nothing at all**
   (not even a toast). Replaced with an **event channel**: every tap opens the dialog.
   Also, when a world is already selected, its backups are listed directly instead of sending you back
   to the world picker.

2. **NBT values stayed Chinese after switching to English** (real root cause)
   Strings were resolved from the **Application context**, which **does not follow the in-app language
   setting** and always uses the **system language**. So with a Chinese system and an English app,
   buttons were English while values read "0: 生存 / 1: 创造".
   The context is now built with the **app's own language**, and resource files are chosen from it too.

3. **Switching the language left stale text behind**
   `recreate()` **does not destroy the ViewModel**, so the translation cache and already-rendered
   list/tree rows were never refreshed. The app is now **fully restarted**.
   As requested: tapping the language button first shows a **confirmation dialog** (the app restarts and
   unsaved edits go to the draft box), and only proceeds if you accept. The current edit is flushed to the
   draft box before switching.

4. **The permission dialog was "pushed away by the system settings page"**
   There were **two** request paths on startup, and one of them **jumped to system settings with no dialog
   at all**, pushing the explanation dialog away.
   The unconditional startup request is gone. There is now a **single entry point** that **always explains
   first**, and only opens settings after you tap "Go to grant". Requests now happen when actually needed
   (save / switch path / manual "Check permissions") and support a **"Don't ask again"** checkbox.

5. **The old-data migration prompt never appeared**
   It was hidden behind the permission dialog, and the original "remind only once" design meant that being
   hidden or dismissed once **silenced it forever**.
   It now reminds **as long as the old folder still has content** (and stops naturally once it has been
   migrated or emptied).

## 📌 Not touched in this build

- Icon, app name, package name, data-folder migration logic (unchanged from 1.0.4a)
- Known issues such as low memory on large worlds and map plane editing (still on the to-do list)
